## [0.4.0] — 2026-10-10

Sequence art direction + the Discovery template.

### Added

- New `discovery` template — Apple-inspired product-page art direction: an
  optional interface-inspired search layer rendered strictly OUTSIDE the app
  screenshot with localized text from the new `screenshots[].prompt` field
  (only marketplace/search apps need to set it), oversized ghost typography,
  and layered app screens cropped by the canvas edges. Two portrait variants
  plus landscape, all RTL-aware.
- Structurally different portrait layout variant B for every template
  (deterministic on odd sequence positions): editorial centered spread with
  bottom-bleeding device, cinematic towering product over a scrim, swiss
  giant-type page, campaign typography behind the device, immersive
  edge-cropped twins, showcase full-bleed slab.
- Google Play `feature-graphic` profile (1024x500, verified) and gallery
  coverage; device realism pass (screen-edge vignette, rail specular
  highlight).
- Before/after gallery rebuilt from real CLI renders with Arabic examples;
  every markdown image reference is verified to resolve on disk.
## [0.3.0] — 2026-10-10

Apple creative assets + landscape compositions.

### Added

- New App Store export profiles, verified against Apple's creative-assets
  specifications on 2026-10-10: `header-21-9` (3840×1646 product page
  header), `header-16-9` (5244×2950 universal PNG for header AND search
  results), `search-results-3-2` (3840×2560 dedicated search creative),
  `iphone-6-1` (1179×2556 alternative screenshot size) and
  `preview-frame-6-3` (886×1920 still for app-preview production).
- Landscape compositions for every template: when the export canvas is
  wider than tall, templates switch to art-directed landscape layouts
  (text column + device column, RTL-mirrored, per-template character
  preserved — masthead/column rule, key light/reflection, grid, brand
  band, horizon/twin, slab).
- Landscape gallery in `docs/gallery/landscape`; visual-regression cases
  for the 21:9 and 3:2 aspects in English and Arabic; an integration test
  rendering the real 3840×1646 header through the CLI.
## [0.2.0] — 2026-10-10

The creative redesign. Generated screenshots are now art-directed marketing
compositions with sequence awareness, realistic device rendering and a full
design-token system. See docs/before-after.md.

### Added

- Six art-directed templates — `editorial`, `cinematic`, `swiss`,
  `campaign`, `immersive`, `showcase` — each with its own layout rules,
  typographic character and device presentation.
- Device rendering system with three modes: frameless (`bare`), premium
  front-facing hardware (`front`: rail, bezel, glare, island, buttons,
  layered shadows) and perspective scenes (`angled`: rotation, optional
  twin device, ground shadow). Exact screen aspect guaranteed; the assembly
  never exceeds its slot.
- Design-token layer (`src/design/tokens.ts`): light/dark derivation,
  surfaces, hairlines and three shadow levels shared by every template.
- Composition primitives: five headline typographic characters, masthead
  with folio, overlines, chips — all carrying the overflow-measurement
  attributes.
- Sequence awareness: templates receive `index`/`count`/`role` and
  alternate layouts deterministically across a campaign; `screenshots[].role`
  config field.
- Theme tokens: `theme.surface` and `theme.mode` (auto/light/dark).
- Display typography: bundled Fraunces (variable, SIL OFL 1.1) with a
  direction-aware font stack — Arabic headlines stay IBM Plex Sans Arabic
  with Latin words falling through to the serif.
- Six wizard theme personalities incl. light presets; five example app
  screens (two new: focus timer, Arabic weekly planner) and a full
  five-image example campaign.
- Gallery builder (`scripts/build-gallery.mjs`) rendering every template ×
  locale + light themes + the complete campaign into `docs/gallery`.
- New unit tests for design tokens, device math and mode resolution; visual
  cases for all six templates incl. long Arabic headlines, mixed
  Arabic/English/numerals copy and light mode.

### Changed

- Template registry replaced; pre-v0.2 ids resolve through aliases
  (minimal→swiss, gradient→campaign, device-focus→immersive,
  spotlight→cinematic) with a deprecation notice from generate/validate.
- Template settings unified around `headlineScale`, `deviceScale`,
  `deviceMode` + a small per-template set.

### Fixed

- Framed devices could exceed their layout slot by the bezel/rail width;
  the screen is now fitted inside the slot minus chrome (caught by a unit
  test).

## [0.1.0] — 2026-10-10

First public release.

### Added

- CLI (`storeshot`) with `init`, `generate`, `validate`, `templates` and
  `install` commands; interactive project wizard on `init` (TTY) with
  `--yes` for CI.
- JSON configuration with a published JSON Schema (`storeshot-cli/schema.json`),
  Zod validation and actionable, aggregated error messages.
- Arabic/RTL first-class support: locale-driven `dir`, CSS logical-property
  mirroring, Chromium text shaping, bundled IBM Plex Sans / IBM Plex Sans
  Arabic (SIL OFL 1.1), per-locale direction overrides.
- Four templates: `minimal`, `gradient`, `device-focus`, `spotlight` — all
  RTL-aware, all with documented settings.
- Store export profiles verified against official Apple / Google
  documentation on 2026-10-10, custom size support with Google Play rule
  enforcement, and a documented list of constraints StoreShot does not
  check.
- Deterministic local rendering through Playwright Chromium with network
  blocking, exact-pixel output verification and per-asset diagnostics.
- Validation covering schema, missing/corrupt/low-res assets, font
  fallbacks, missing translations, unknown templates/profiles/settings,
  contrast warnings, and rendered text-overflow measurement per locale ×
  screenshot × export.
- Exit codes for CI (`0` / `1` / `2`) and `storeshot validate --json`.
- Test suite: unit (schema, i18n, profiles, naming, image headers),
  integration (init/generate/validate through the built CLI) and visual
  regression (determinism + per-platform baselines with a documented update
  flow).
- Starter project shipped inside the npm package; showcase gallery and docs
  (configuration, template authoring, RTL troubleshooting, store profiles).
